# 校准工具 GUI

## 概述

CalibrationGUI 提供了一个图形用户界面，用于实时调整坐标变换参数和记录误差数据。

## 功能特性

### 1. 参数调整
- **平移参数**（Tx, Ty, Tz）：单位 mm，步长 1.0 mm
- **旋转参数**（Pitch, Yaw）：单位度，步长 0.1 度
- 支持通过 [+]/[-] 按钮微调
- 支持直接输入数值

### 2. 参数操作
- **设置参数**：应用当前输入的参数值
- **重置为默认**：恢复到启动时从配置文件加载的初始参数

### 3. 误差记录
- 设置基准位置（X, Y 坐标）
- 记录实际检测位置与基准位置的误差
- 显示已记录的数据条数
- 误差数据保存到 `logs/calibration_errors.json`

## 使用方法

### 启动GUI

```python
from tools.calibration_tools.gui.calibration_gui import CalibrationGUI
from tools.calibration_tools.core.transform_param_manager import TransformParamManager
from tools.calibration_tools.core.error_recorder import ErrorRecorder

# 创建必要的实例
param_manager = TransformParamManager(config_manager, data_processor)
error_recorder = ErrorRecorder(decision_layer)

# 在独立线程中启动GUI
gui_thread = CalibrationGUI.start_in_thread(param_manager, error_recorder)
```

### 参数调整工作流

1. **微调方式**：
   - 点击 [+] 或 [-] 按钮
   - 输入框自动更新显示
   - 点击"设置参数"应用更改

2. **直接输入方式**：
   - 在输入框中输入目标值
   - 点击"设置参数"应用更改

3. **重置方式**：
   - 点击"重置为默认"
   - 自动应用初始参数
   - 输入框自动更新显示

### 误差记录工作流

1. 在"基准位置 X"输入框输入 X 坐标（如：1000.0）
2. 在"基准位置 Y"输入框输入 Y 坐标（如：500.0）
3. 点击"记录误差"按钮
4. 系统从输入框读取基准位置
5. 从 DecisionLayer 获取当前目标位置
6. 计算并保存误差数据
7. 更新"已记录"计数

## 技术细节

### 线程模型
- GUI 运行在独立的 daemon 线程中
- 不阻塞主系统运行
- GUI 异常不影响主系统

### 单设备限制
- 仅支持单设备运行模式
- 启动时自动验证设备数量
- 如果不是单设备，会抛出 ValueError

### 参数更新机制
- 参数更新仅在内存中生效
- 不修改配置文件
- 通过 TransformParamManager 更新变换矩阵

### 误差数据格式
误差数据保存为 JSON 格式：
```json
{
  "timestamp": "2024-01-15T10:30:45.123456",
  "target_type": "durian",
  "reference_position": {"x": 1000.0, "y": 500.0, "z": 0.0},
  "actual_position": {"x": 1005.2, "y": 498.3, "z": 2.1},
  "error_vector": {"dx": 5.2, "dy": -1.7, "dz": 2.1},
  "error_magnitude": 5.67
}
```

## 依赖项

- tkinter（Python 标准库）
- TransformParamManager
- ErrorRecorder
- logging

## 注意事项

1. **启动顺序**：必须先启动主系统，再启动校准工具
2. **单设备模式**：仅支持单设备运行
3. **线程安全**：所有操作都是线程安全的
4. **参数不持久化**：参数更新仅在内存中生效
